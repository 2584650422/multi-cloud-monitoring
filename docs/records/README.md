# 实施记录

此目录保存按日期或阶段产生的实施事实、试点结果、UI 调整和待验证事项。它们用于交接、复盘与追踪，但**不是**部署手册的权威来源。

部署、配置和日常操作应优先阅读上级 `docs/` 目录中的安装手册与 Runbook。某项记录落地后，应将可复用的最终步骤提炼回对应部署文档；记录本身保留当时的上下文与结论。

- `implementation-status.md`：项目当前事实与边界快照。
- `gateway-pilot.md`：Gateway 路径的试点与端到端验证记录。
- `dashboard-1860-optimization.md`：Grafana Dashboard UI 调整记录。
